## Estrutura de um Prompt de Capa Eficaz

```
[ESTILO ARTÍSTICO], [COMPOSIÇÃO], [ELEMENTO PRINCIPAL], 
[PALETA DE CORES], [MOOD/ATMOSFERA], [TIPOGRAFIA], 
[RESOLUÇÃO/QUALIDADE], [PLATAFORMA DE DESTINO]
```

## Dicas de Prompt Engineering para Capas

1. **Especifique o formato:** sempre inclua `1600x2560px book cover` ou `A4 ebook cover`
2. **Mencione a tipografia:** `bold title typography visible` ou `space for title at top`
3. **Controle o realismo:** `photorealistic`, `illustration style`, `flat design`
4. **Use negative prompts (Midjourney):** `--no blur, text, watermark, low quality`
5. **Itere com variações:** gere 4+ versões e escolha a base para refinar
